# Kaviyarasi M | Data Analytics & AI/ML Portfolio

Personal portfolio of Kaviyarasi M, B.Tech Information Technology student specializing in Data Analytics, AI/ML, Python, SQL, and Full Stack Development.

## Run locally
Open the folder in VS Code and use the Live Server extension on `index.html` (or just open `index.html` in a browser; internet needed for the Three.js CDN script).

## Structure
- `index.html` - page markup
- `css/style.css` - styles
- `js/main.js` - interactions, project modals, Kavi AI assistant, 3D hero
- `assets/` - profile photo and resume PDF

## Deploy
GitHub Pages: Settings > Pages > Deploy from branch > main > / (root).
